## 今日判断

- 【必看】定时运行的 agent 先补齐两条最常被忽略的规则：按书签而不是固定时间窗增量读取（窗口随上次运行时间伸缩，迟跑不漏、早跑不重），以及源读取失败时报告「读不到」而不是「没新内容」并保留书签不动；这两条直接决定无人值守 agent 会不会悄悄丢数据。
- 【必看】生产 agent 要有一条外环质量回路：从生产轨迹抽样，审查后聚类，再用另一个模型对照原始记录验证去伪，最后按部署时的源码快照定位根因。AQuA 在 travel-concierge 上 9 个候选聚类被拒掉 3 个误报，两处一行的 prompt 修复让全会话通过数翻倍以上；只看健康检查和 HTTP 200 会漏掉在对话内部、不报错的失败。
- 【警示】自演进出来的验证器不能用下游任务分数来验收：去掉锚点约束后，验证器退化成永远判通过，但用它训练 skill 的分数并没有变差。验证器必须单独对照一个带锚点的小参考集测一致率；skill 库的修订也要对历史回放做不回归检查（Skill-V），不能只看新任务成功率。
- 【结论】先读失败构成，再决定调 harness 还是训练权重：流程类失败（调用被拦、死循环、步数耗尽）靠改 harness 修，内容类失败（交付了但质量差）才需要训练权重；在演化后 harness 的轨迹上训练的 LoRA，即使换回原 harness 也能保住 +0.13。
- 【值得盯】模型固定、预算有限时，可靠性主要来自缩小动作空间，而不是给模型更多开放工具：统一查询面、事先侦察 schema、只保留一条写答案的路径、文档交给单独的 temperature 0 调用处理（NVIDIA KDD）。同理，按调用点选模型时，五个调用点里四个本地小模型和托管模型在统计上没有差别，只托管两个生成类调用点就能把花费降到 28%。

## ⭐ 自演进重大发现

- **带硬数据的自演进 SOTA：冻结 LLM 只靠外部记忆通关 ARC-AGI-3 全部公开游戏**。《Memento 3: Model-Based Recursive Self-Improvement through Reflective Rulebooks》（2026-10-08 提交，HF 组织 UniversityCollegeLondon）让底座 LLM 保持不变，agent 用自然语言规则书记录关于环境动态的可修订假设，再把规则书编译成可执行代码，用于预测和规划；循环是观察、反思、修订规则、编译、验证。新代码只有在 LLM 判定它忠于规则书、并且逐格回放能复现所有已观测的状态转移时才被接受。单模型版本通关 ARC-AGI-3 全部 25 个公开游戏，平均 RHAE 100.0，动作数是人类的 44%；在 Pong 案例中，学到的控制器 3 局都 21:0 获胜，过程中不再调用 LLM。这是「不改权重、只改外部模型并逐步验证」这条路线迄今最硬的成绩。同期《RSIGym》在 500 美元预算下测出 Opus 5 的 RSI-Index 为 0.4809，是首个横向比较前沿模型自主改进系统能力的量化环境。
