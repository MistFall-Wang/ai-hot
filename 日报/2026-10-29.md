## 今日判断

- 【必看】Anthropic 实验里专家 86% 跟着 agent 的倾向走、77% 复述 agent 的论据却不自知，经验和专业度都不能免疫。做判断型 agent 时，凡是有多个合理选项的决策，必须让 agent 对每个选项都给出最强论证并标明「这是我先提的」，否则所谓人在环上只是走形式。
- 【必看】Google 睡眠框架和 UIUC 的 Memory Tax 合起来说明：记忆不是加了就有用，很多专门记忆系统不如对原始历史做朴素 RAG。上线记忆模块前先跑 RAG 基线算净增益；经验写入要像睡眠框架那样放到固定的离线周期里做蒸馏、筛选、验收，不要边跑边写。
- 【利好】skill / harness / 工具层的自进化方法本期集中出现且都带数字：Skill^∞ 超过人工 skill，GEPA-Curator 比 GEPA 高 20.7%，AT-AT 在企业生产 MCP server 上降了成本或错误率。但 Treude 的实证里 12 条自提的 harness 改动只有 3 条真有效，RSI Arena 里有模型安全性回退。自进化落地的最低配置是「改动必带后续任务验证 + 安全回归」。
- 【值得盯】Gemini 4 Carbon 把作弊率 0.0%、越权减 26%、无依据断言减半、提示注入 0.0% 和能力分数并列写进发布说明，并且先只给网络防御者。模型厂商两周一代、对齐指标进发布页，agent 评测表应该照加这四项。
- 【结论】评测与成本观测正在工具化：Agents CLI 的 eval 闭环、harness 验证设计的量化比较（独立 critic 评审性价比最高）、Claude Code 的 OTel 按 skill / 插件 / MCP 拆分成本。把「每次改动跑一分钟评测、每天看一次成本分布」当作基础设施，而不是上线前的一次性动作。

## ⭐ 自演进重大发现

Google Research 官方博客 10 月 27 日提出「睡眠框架」（The sleep framework），给自改进定了一套可验收的节律：部署后的模型在清醒期只把新信息存进短期记忆，到睡眠期先做「记忆巩固」（解锁预留的低秩 MoE 专家作为长期记忆块，用 on-policy 蒸馏加 RL 模仿学习把短期记忆写进参数，再重置短期参数），再做「做梦」（随机激活非常规专家生成合成样本，按梯度筛选后自训练，按下游任务验收）。硬数字：未见语言连续翻译近零遗忘而 ICL、Cartridges、SFT 严重遗忘；BABILong 扩到 1000 万 token 近乎完美，超过 GPT-4 与 Titans；SQuAD 新知识注入 48.9% 超过 SEAL；AIME 24/25、HMMT 25 为 79.2%、69.0%、46.1%，超过 SFT、GRPO、OPSD。作者明确整个过程在固定架构和人定训练规则内进行。这是厂商官方第一次把「持续学习 + 自生成数据自改进」做成一个带全套对照数字的统一框架。

## 官方长文（工程/研究）

- 【必看】**[How AI agents shape experts' judgment calls](https://www.anthropic.com/research/agents-judgment-calls)** · 出处：Anthropic Research（作者 Amaç Herdağdelen、Hailey Joren、Alex Tamkin，附论文 PDF）· 2026-10-27 —— 随机对照试验：50 名有因果推断经验的专业分析师，在内置 Claude Code（Opus 4.8，High effort）的网页版 VS Code 里评估一个虚构农业合作社的咨询项目是否值得推广。中间四个分析决策（产出口径、比较方法、覆盖范围、加权）和最终建议都各有两个合理选项。研究者用隐藏系统提示让 agent 对每个决策按抛硬币结果「倾向」一边，并要求它诚实论证、证据不利时改口、绝不误导。结果：四个分析决策分析师 86% 跟了 agent 的倾向（无影响应为 50%）；已先表态的人在 agent 反对时 60% 改主意，赞同时只有 6%；事后 77% 用 agent 的原话解释选择，只有 15% 提到 agent；仅凭四次抛硬币就能预测 82% 的最终建议；经验、学历、对 AI 的信任等 10 项特征都预测不了谁会顺从。不用 agent 的 11 人里 55% 犯了严重方法错误（用的人 6%），耗时也更长（中位 90 分钟对 65 分钟）。作者指出：多个团队依赖同一模型的偏好时，结论「一致」就不再独立，AI 安全研究里的人工复核同样面临这个问题。局限：故意强化了 agent 的倾向，只测了一个任务、一个领域、一个模型。**可借鉴**：agent 给判断型建议时，要求它对每个合理选项都给出最强论证而不只论证自己的倾向，并在产出里标注「哪些决策是 agent 先提的」，否则人类复核会变成走形式。
