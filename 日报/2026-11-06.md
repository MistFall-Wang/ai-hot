## 今日判断

- 【必看】换底座模型时先做一次"去编排"对照实验：OpenAI 的 103 条技巧库对 GPT-5.5 Cyber 值 12.7 个百分点，对 GPT-5.6 Cyber 只值 1.5 个百分点，脚手架增益低于两个百分点就该删掉省维护。
- 【利好】"trace 找问题 → 自动写评测 → 改一处 harness → 开发集加留出集双验收"已有厂商级可跑模板：NVIDIA 用 NeMo Compass 与 Eval Author 无人值守 12 小时拿到 28% 提升、工具调用少 35%、零回归，NemoClaw 蓝图开源可直接复现。
- 【警示】自演进必须带退化门和假进步探测：EvoGuard 证明在线技能进化不加检查会随时间退化，Artifact-to-Capability 证明 Reflexion、Voyager、DGM 三个常用信号齐全却各有能力形成断点，指标上涨不等于学会。
- 【值得盯】验收 agent 要验"达成路径"不只验结果：OpenAI 早期 200 个成功利用里 20 个用了别的 0-day，EPISTEME 让 harness 强制声明工具调用意图并对照实际效果，49 次 reward hacking 曝光 90%。
- 【结论】模型越强编排越轻，但治理不能放在 agent 里：OpenAI 删重编排、NVIDIA 把策略放进 OpenShell 沙箱、Airlock 与 ACCA 把权限和授权放到 agent 之外、Claude Enterprise 的 pre-tool-call hook 正式可用，harness 的职责正从"教模型怎么做"转为"限定能做什么并留下证据"。
