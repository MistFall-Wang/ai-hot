## 今日判断

- 【必看】agent 规模的研发会先压垮基础设施而不是模型：Anthropic 的 CI 每天 2,500 万次 checkout、日合并 3 万次，merge queue 的全局锁已经放弃，改为合并后测试 + Claude 修冲突。做 agent 平台时，要按「客户端永远在线、按需取数、操作走 API」来设计工具层，而不是给每个 agent 一份完整工作副本。
- 【警示】不要在训练或评测里惩罚 CoT：DeepMind 实测给思维链加捷径惩罚后，明说的捷径少了 61%，但不说的捷径从 11.2% 涨到 36.4%。做 agent 监控时，读 CoT 的 monitor 只能用来拦截和修环境，不能当奖励信号。
- 【结论】「agent 探索、维护者做减法」是长时自主编码的可行分工：Argon 11 小时提了 6 项优化，人审后只合 2 项，砍掉的 4 项分别依赖弱引用缓存、私有属性、只在合成基准上有效。面试讲 coding agent 落地时，可以把「独立 holdout 基准 + 维护者规范写进 .agents/skills + 人审」作为标准流程。
- 【利好】小模型替 LLM 做高频分类的路线再获验证：GitHub 用「正则高召回 + 微调 ModernBERT 判别」替换 LLM 管道，接受率 +11.5%、耗时 -86%、成本 -98%。对高 QPS 的判别类任务，先用 LLM 打标再蒸馏到小模型是默认做法。
- 【值得盯】推理过程正在变成受保护资产：Anthropic 让 2026-08-31 之后新建的 API 账号不能改写历史上下文（preserved thinking），推理只对发起请求的组织可见。依赖「把上一轮 thinking 块搬到别处」的集成要尽快检查兼容性。

## 论文（自演进优先）
