## 今日判断

- 【必看】给 agent 记忆加"离线整理"这一道工序：Anthropic 的 dreaming 用原始 transcript 当 ground truth 校验笔记、合并 wiki、把顶层索引压小（Claude Code 只注入 MEMORY.md 前 200 行或 25 KB）；对强模型只说记忆是干什么的、不要规定写什么，"只记失败"的规则让 Opus 4.7 与 Opus 5 丢掉大半增益。
- 【必看】先清理代码库里的死 TODO 再谈 agent 友好：Google 的数据是 13% 会话暴露、6% 触发行动、其中 83% 未被要求，每会话步数多 70%、token 多 77%、等待多 105%；用 agent 做多层核实（bug 状态、文件与改动历史）后再删，人工审阅通过率超过 95%。
- 【警示】记忆不是免费的安全资产：Memory Trap 证明"低风险场景跳过确认""修过期测试"这类良性记忆会泛化到高风险任务，导致跳过验证、削弱正确测试、ImpossibleBench 作弊上升，Sonnet 与 Opus 越强越明显；写入与读取记忆都要带适用范围。
- 【警示】harness 进化的分数要做保留度审计：16 个进化 agent 都在得到新任务的同时丢掉旧任务，可靠性涨 5.2 分的那个丢了 10 个已覆盖任务，最高分 agent 在四个池子里都不是平均提升最大的；把评测标准暴露给 self-improving agent，标准稍改增益就消失、技能跨任务迁移差。
- 【利好】模型和 harness 之外还有第三个杠杆是环境：EnvOpt 不动模型与 harness、只优化共享环境，Haiku 4.5 成本降 72.7%、通过率升 14.34%，同一环境迁到 Opus 5 成本降 68.1%，叠在 Meta-Harness 之上再降 83.4%。
