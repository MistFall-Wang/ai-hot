## 今日判断

- 【必看】**harness 改动要用「验证通过率 + 轨迹」双证据验收，少几次调用不算改进**。NVIDIA 的 108 次 A/B 里，同一批工具层修复让 Qwen3 Coder 多做成 3 个任务，但 LLM 调用多 29%、耗时多 56%，对 Sonnet 4.5 没有变化；自己改 prompt / 工具后，按「固定任务、确定性验证器、两臂等次数」重跑再下结论。
- 【结论】**自演进循环的短板在验收闸门，不在提案器**。SAGE 显示「平均分涨了就接受」会放进永久回归（DeepSeek-V4 上 LiveMath 36.5%、OfficeQA 42.8%），换成逐题配对检验后降到 0 且最终分更高；VACE 的 44 个 harness 提案有 17 个在新检查点上是负收益。给任何自动改 prompt / skill 的流程加逐题配对对比。
- 【警示】**可跨会话携带的推理密文是攻击面**。OpenAI 被人用「把 A 会话的加密推理贴到 B 会话让模型解密」的方式批量提取推理，并确认会话压缩也有同类路径；自己的系统若转存、回放 reasoning item 或压缩摘要，要把它们绑定到用户 / 工作区 / 组织，并对流式输出加泄露检查。
- 【利好】**$2 / $10 这一档出现第三家**。Gemini 4 Argon 预告价与此前日报记录的 Sonnet 5.5、GPT-6.1 Sol 相同，缓存输入再减 95%，输出上限 1M token；但目前只给网络防御者，开发者暂时用不到，路由层先留位置、等开放后用自己的任务集测。
- 【值得盯】**大厂开始自报生产级自改进数据**。微软 AI Software Factory 的 3 倍工程效率、22 倍 token 效率只有 6 页摘要级描述，后续若有完整论文或官方博客，重点看 World Model 数据底座的结构和自改进的验收方式。

## 官方长文（工程/研究）

- 【必看】**[Tracing Agent Harness Behavior with NVIDIA NeMo Relay](https://developer.nvidia.com/blog/tracing-agent-harness-behavior-with-nvidia-nemo-relay/)** · 出处：NVIDIA 开发者博客（Agentic AI / Build AI Agents） · 2026-09-30 —— **整体概括**：教程用 Hermes Agent 内置的 NeMo Relay 记录会话、轮次、模型调用、工具调用的生命周期事件，输出三种轨迹：ATOF（JSONL 事件流，用于审计单个事件与父子关系）、ATIF（逐步轨迹，用于评审路径）、OpenTelemetry + OpenInference（进 Phoenix、LangSmith 等）。文中强调 ATIF 里的工具请求不等于执行结果，要到 ATOF 里配对开始 / 结束事件确认。评估 harness 改动的流程：固定任务与自动化成功检查，只改一处，模型快照、预算、超时全部不变，两臂等次数重复，先比验证结果再看轨迹。Hermes ToolPerf 案例（Nous Research 从生产会话挖出九类失败模式）：9 个任务 × 3 次 × 2 个模型 × 2 臂共 108 次；Claude Sonnet 4.5 从 24/27 变为 23/27，无实质变化；Qwen3 Coder 30B 从 19/27 升到 22/27，但平均 LLM 调用 3.8 → 4.9、工具结果数据 16 KB → 33 KB、耗时 27 秒 → 42 秒；其中被拦截命令任务 33% → 100%，大小写不敏感搜索任务反而从 3.3 轮退化到 9.3 轮。**可借鉴**：判定标准写成一句话——只有通过率可重复地上升，或通过率不变而目标指标（可靠性、延迟、成本）改善，才叫改进；单次更快或调用更少只能用来解释结果。

- **[What work can robots do?](https://www.anthropic.com/research/what-work-can-robots-do)** · 出处：Anthropic（/research，Economics） · 2026-09-30 —— **整体概括**：提出机器人岗位暴露度指数。方法：以 O*NET 约 900 个职业、约 19,000 条任务为底，先让 Claude 按量表筛出体力任务，再让 Claude 为每条任务生成带时间占比的具体做法示例，用网页搜索找已部署、在售或已演示的机器人并直接引用来源，按环境结构化程度打四档（E0 做不了、E1 专用机器人环境、E2 结构化人类工作场所、E3 非结构化环境），按工时加权多数决定档位。结论：现有机器人能做美国 74% 的体力任务，占工时 34%，多数限于受控环境；机器人与 LLM 合计暴露约 80% 的工时；但机器人只在 0.3% 的任务上比人工便宜，按历史降价趋势要 40 年才到 10%。用 1977 年至今的数据回测，暴露度高的职业此后工资和就业下降更多。**可借鉴**：大规模 LLM 标注的做法——先把抽象条目展开成带权重的具体示例再打分，强制引用来源，并用历史回测验证量表。

## 论文（自演进优先）

- **[SAGE: A Statistical Acceptance Gate for Self-Evolving Agents](https://arxiv.org/abs/2609.36043)** · Yihao Wang 等 9 人 · 提交 2026-09-28 ⭐ —— 自演进循环分提案和验收两步，以往只研究提案，验收沿用「验证集平均分涨了就保留」。这条规则有两个问题：平均分上升可以掩盖已解题目被改坏；有限且有噪声的验证集上取最优会系统性高估。SAGE 改为在相同题目上对新旧 skill 做逐题配对比较，不对称地惩罚回归，并用单侧配对检验，只有胜出在统计上可靠才提交。五个基准 × 四个模型等预算下，20 组里 19 组回归率下降；DeepSeek-V4 上 LiveMath 回归率 36.5% → 0、OfficeQA 42.8% → 0，20 组最终分全部最高。**可借鉴**：验收从「比平均分」换成「逐题配对 + 显著性检验，不显著就不收」。
