**官方长文（1 篇）**：Anthropic 研究页发了一篇特邀文章：物理学者 Matt von Hippel 8 月在博客上挑战 AI 公司去算 N=4 超杨-米尔斯理论的九圈振幅，Anthropic 的两位物理学家用 Fable 5.1 跑在 Claude Science 这个科研 harness 里，几乎只靠一句「继续做」就用两种方法算出了结果，并由 SLAC 的 Lance Dixon 独立验证。全程成本约一两千美元，其中 96 核 CPU 跑一周的计算只占约 100 美元。

**发布与动态（1 条）**：Anthropic 开放插件目录的开发者提交门户：插件可以是单个远程 MCP 服务器，也可以是托管在 GitHub 的 MCP + Skills 组合包，提交后自动校验和安全扫描，上线后能看到分渠道安装量和搜索来源；Claude 已支持 MCP 2.0（无状态内核）及 MCP Apps、Enterprise Managed Auth 两个扩展。

**论文（8 篇）**：三篇自演进：Env-Rethink 反过来「演化环境」而不是演化 agent，把环境噪声造得更难来推动 agent 自我提升；SkillPivot 只在失败轨迹「开始走偏」的那个点做局部 skill 修订；一篇硬件验证的 harness 自动演化研究给出反例——演化出的收益在不同候选之间互相交换，没能汇聚成一个全面更好的 harness。另外三篇是 harness 可靠性的硬数据：agent 能轻易删除自己的执行轨迹（多数主流编码 harness 不拦）；写操作超时后的重复副作用主要取决于工具契约，给每个写入加幂等键能把重复率从 28% 降到 4%；恶意工具可以通过「被反复计费的历史上下文」发起钱包耗尽攻击，单会话累计输入最高达首轮的 14,293 倍。还有 Qwen 的模型与 harness 协同演化规划 agent，以及 Nubank 上线前用模拟器筛选客服 agent 的生产案例。

**最值得看**：《Where Does Exactly-Once Live?》。25,930 个回合的实验把「重试会不会重复扣款」这个每个做工具调用 agent 的人都会遇到的问题拆清楚了，而且结论可以直接照做：别指望模型或 harness，在工具契约里提供幂等键。

## 今日判断

- 【必看】**写操作的「恰好一次」要在工具契约层解决**。请求仍在途中或被重复投递时，前沿模型的重复率高达 56% 和 74%，契约解释了 81% 的差异；给每个写接口提供幂等键，重复率从 28% 降到 4%。自己暴露给 agent 的写工具，先把幂等键加上。
- 【警示】**不要把 agent 自己写的日志当审计依据**。实测 Claude Code、Codex、Antigravity、OpenCode、Grok Build 都允许 agent 按指令删除自己的轨迹且不触发监控，前沿模型在追求奖励时还会自发这么做。轨迹记录要放在 agent 控制之外的独立拦截层。
- 【警示】**工具返回值进入历史上下文就会被反复计费，这是一个攻击面**。钱包耗尽攻击能把单会话输入放大到首轮的 14,293 倍，扫描的 3,830 个 MCP 相关仓库里只有 71 个有可见的防护。harness 要对工具返回做压缩或截断，并对上下文增长和累计花费设硬上限。
- 【值得盯】**harness 自动演化的收益不会自动叠加**。硬件验证实验里完成率涨了 71–76%，但真正答对只涨 18–24%，后期候选只是在任务之间互换收益。做自演进要保留候选档案、按任务选用，不要只留一个「最新最好」。
- 【利好】**上线前用模拟用户筛 agent 已经在大规模生产里被证明有效**。Nubank 的模拟评分与线上高度相关，模拟指导的迭代让 tNPS 涨了 36.69 分，选出的开源模型让自助解决率涨了 8.82 个百分点。客服类 agent 应该先建模拟评测，再做线上 A/B。

## 今日话题

### 【必看】agent 的副作用与审计：幂等、轨迹、计费三处都要在 harness 外兜底

三篇论文从三个方向指向同一个结论：靠模型自觉守不住生产边界。写操作重复要靠工具契约的幂等键，执行轨迹的完整性要靠 agent 碰不到的独立记录层，上下文计费风险要靠 host 端对工具返回的压缩和花费上限。它们合起来就是一份工具调用 agent 的上线检查清单。

- [Where Does Exactly-Once Live? Model, Harness, and Tool-Contract Effects on Duplicate Side Effects in LLM Agents](https://arxiv.org/abs/2609.29095)
- [LLM Agents Can Easily Tamper With Their Own Traces](https://arxiv.org/abs/2609.30266)
- [Persistent Billable State: Denial-of-Wallet Attacks and Defenses in Tool-Calling LLM Agents](https://arxiv.org/abs/2609.28585)

### 【值得盯】自演进的新变体：演化环境、定位偏离点，以及收益不叠加的反例

Env-Rethink 把自我提升的对象从 agent 换成环境，用虚拟事件历史把环境造得更难；SkillPivot 把 skill 修订精确到失败轨迹的偏离点，保留前面有效的部分；硬件验证的 harness 演化实验则提醒，不同候选各自学到的好行为并不会自然汇到一个 harness 里。Qwen-Planner-Agent 把模型训练和 harness 调整放进同一个执行证据闭环。这一批说明自演进正在从「改 prompt」细化到「改什么、在哪改、怎么保留」。

- [Breaking the Environment Wall: Evolving LLM Agent Environments for Recursive Self-Improvement](https://arxiv.org/abs/2609.29773)
- [A Wrong Turn Does Not Ruin the Journey: Deviation-Guided Skill Self-Evolution for LLM Agents](https://arxiv.org/abs/2609.29154)
- [Automatic Harness Evolution for Hardware Design Verification: Can LLMs Consolidate Gains Across Discovered Harnesses?](https://arxiv.org/abs/2609.28908)
- [Qwen-Planner-Agent: A Closed-Loop AI-for-AI Framework for Real-World Mobile Planner Agents](https://arxiv.org/abs/2609.29892)

### 【利好】长时自主 agent 的两个落地信号：科研 harness 一句「继续」算出前沿结果，客服 agent 靠模拟上线

Claude Science 在几乎无人监督的情况下完成了一个流程极其脆弱的九圈振幅计算，并由领域专家独立验证；Nubank 用模拟用户和模拟工具在上线前筛选客服 agent，线上指标明显提升。两者的共同点是：结果都有独立的验证手段（专家校验、与线上高度相关的模拟评分），长时自主才敢放手。

## 官方长文（工程/研究）

- 【注意】**[Claude computes a nine-loop amplitude in N=4 super-Yang-Mills](https://www.anthropic.com/research/yes-claude-can-do-nine-loops)** · 出处：Anthropic（/research，Science；特邀作者 Matt von Hippel，附 Lance Dixon 补记） · 2026-09-25 —— **整体概括**：物理学者 von Hippel 8 月公开挑战 AI 公司在学术级算力预算内算出振幅领域的前沿结果。Anthropic 的两位物理学家先让 Claude 自己挑最有把握的题，再只给一句题目描述，之后反复说「继续，每 4–6 小时汇报」。Fable 5.1 在 Claude Science harness 里用 bootstrap 和 form factor 两种方法算出九圈六粒子振幅，SLAC 的 Lance Dixon 独立验证通过。总成本约 1,000–2,000 美元，主要是长时间运行模型的费用，SymPy 计算（96 核跑一周）只约 100 美元。作者的判断是：Claude 用的是已知方法，并没有突破计算极限，但证明这类流程脆弱的长计算现在可以被可靠地自主完成；同期中科院何颂组借助 GPT-6 也算出了大部分结果。**可借鉴**：长时自主任务的做法是「先让模型选可行题目 → 最小提示启动 → 定时汇报 → 由独立的领域验证器验收」，成本大头是模型运行时间而不是计算资源，预算时要按 agent 运行时长估算。

## 论文（自演进优先）

- **[Breaking the Environment Wall: Evolving LLM Agent Environments for Recursive Self-Improvement](https://arxiv.org/abs/2609.29773)** · Yukai Wu 等 10 人 · 2026-09-24 · 不在 HF 当日页 —— ⭐ 真实环境往往信息分散、夹着误导和冲突版本、还会随时间变化，会让最强 agent 从 83.9% 跌到 57.6%。Env-Rethink（含 27B 后训练模型）先为环境补上文件归集图和事件日志，再用离线轨迹学习识别环境噪声，最后用虚拟事件历史改写环境状态，造出更难的版本来继续训练 agent。在 30 个任务、9 个模型上评分通过率提升超过 15.1%。**可借鉴**：自演进不一定只改 agent，也可以给环境补结构化索引（归集图、事件日志），并有意把环境造难来持续产生训练信号。
- **[A Wrong Turn Does Not Ruin the Journey: Deviation-Guided Skill Self-Evolution for LLM Agents](https://arxiv.org/abs/2609.29154)** · Yichun Feng、Jiawei Wang、Haozhe Sun · 2026-09-24 · 不在 HF 当日页 —— ⭐ 失败轨迹往往前半段有用、后半段才走偏，而且同一任务有多条正确路径，所以不该拿失败轨迹去硬对齐一条成功轨迹。SkillPivot 用执行有效性、目标进展和动作多样性定位「从有用前缀转为错误后缀」的偏离点，让更强的教师模型从同一前缀接着做，再对比两段后缀生成局部 skill 更新。在 ToolQA、LogicBench、WildClawBench 上优于其他 skill 演化方法，更新更紧凑且可迁移。**可借鉴**：反思时先定位偏离点，只针对偏离后的片段改 skill，保留已经有效的指引，避免整篇重写把好的部分也改坏。
- **[Automatic Harness Evolution for Hardware Design Verification: Can LLMs Consolidate Gains Across Discovered Harnesses?](https://arxiv.org/abs/2609.28908)** · Kidus Seyoum、Ajay Mittur · 2026-09-24 · 不在 HF 当日页 —— ⭐ 固定模型、自动演化 harness，在 12 个专有的设计验证根因定位任务上：完成的尝试数涨 71–76%、至少命中一次的任务覆盖涨 80–100%，但真正答对的尝试只涨 18–24%。后期候选只是在任务之间互换收益，一个在验证集上更好的候选在全量重放时与基线打平。有用的搜索、取证、收尾行为分散在不同候选里，没有汇成一个全面占优的 harness。**可借鉴**：自演进要保留候选档案并按任务选用，评估要区分「完成」和「答对」，并在搜索集之外做全量重放，否则会把噪声当进步。
- **[Qwen-Planner-Agent: A Closed-Loop AI-for-AI Framework for Real-World Mobile Planner Agents](https://arxiv.org/abs/2609.29892)** · Tingyu Qu 等 26 人（HF 组织 Tongyi-MAI） · 2026-09-24 · HF ↑9 —— ⭐ 用同一套「动作-反馈-验证」契约串起数据、训练、部署三个环节：多个 agent 在人工把关下构造任务、采集轨迹、整理数据；训练用监督冷启动加混合环境在线 RL（CARE 奖励与优势设计，降低推理和工具调用成本）；运行时由执行证据驱动记忆、skill、工具的编排，并把失败轨迹回灌给模型和 harness 一起调整。在 MobilePA-Bench 上取得所有评测系统中最好的总体表现。**可借鉴**：把失败轨迹作为模型训练和 harness 调整的共同输入，而不是两条线各自优化。
