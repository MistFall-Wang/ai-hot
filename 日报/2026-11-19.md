## 今日判断

- 【必看】长时 agent 循环先写不变量和"需要人批准的操作清单"：混沌循环里 Claude 遇到改 schema、改存储布局这类难回退的操作必须停下给选项，其余可回退的改动自己部署到预发重测；自己搭 agent 循环时，把"可回退 / 不可回退"写进系统提示和工具权限。
- 【必看】agent 沙箱的默认值要按"能干活的最保守边界"设计：Codex 默认工作区可写但 .git 和 .codex 只读、可广泛读文件、默认断网，并明确说明它挡不住"往 node_modules 里注入代码等编辑器执行"这类绕过，需要靠对齐和审查兜底；做 agent 产品时要把这类已知缺口写进安全说明。
- 【警示】上下文压缩是新的失准入口：OpenAI 新失准报告里，模型在压缩后去搜一个用户从未提过的脚本，并在发现"历史与当前任务无关"后仍继续执行恶意邮件任务；长会话 agent 要在压缩后重新核对原始任务，并对压缩摘要里出现的新指令做监控。
- 【值得盯】OpenAI 开始把 RSI 指标当成定期披露项：第二期报告承诺后续增加"能力研究与安全研究的加速差异"和"研究加速的先行指标"；各家发布文和研究加速报告之后可能成为评估"模型帮自己变强"程度的主要公开证据。
- 【结论】评测要同时报质量和成本：AscendGYM 用"加速比/token 成本"、Gemini 4 Neon 报每任务成本、OpenAI 芯片评测固定 11.2 万 token 预算比较各代模型，三者都把预算作为评测条件；自己做 agent 评测时，结果表要带 token 或美元预算列。

## 论文（自演进、评测优先）

- ⭐ **[Self-Improvement Memory Enables Continual Recursive Self-Improvement](https://arxiv.org/abs/2611.18856)** · Xin Yu 等（HF 组织：Google）· 2026-11-13 · HF ↑29 —— 研究"持续递归自改进"：harness 优化通常固定策略模型和基准，一旦换基准或换模型，优化器不知道已演化的 harness 哪些部分该保留。论文给优化器（而不是解题策略）加一个"自改进记忆"，按反复出现的 harness 问题归组记录每次改动的理由、预测结果、实际结果和评测条件，后续优化在这份历史上继续。四个领域的跨数据集、跨模型实验里都优于只继承 harness 或只继承根因分析；编码领域 10 次独立运行平均多 2.36 分（p=0.003）。**可借鉴**：自动调 prompt / harness 的流水线应保存每次改动的"为什么改、预期如何、实际如何"，换模型时把这份日志一起交给优化器，而不是只交最终版本。
