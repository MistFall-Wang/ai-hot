**官方长文（1 篇）**：《Claude Sonnet 5.5 System Card》。对做 agent 的人最有用的是第 5 章 agentic safety：在 Gray Swan 间接注入基准上，Sonnet 5.5 未加产品层防护时攻击成功率 k=15 为 3.4%（Sonnet 5 为 6.7%），工具调用场景从 6.0% 降到 1.0%；对自适应攻击器 Shade，编码环境成功率 3.01%（Sonnet 5 为 19.47%），电脑使用环境 0.07%（2,800 次尝试中 2 次），与 Opus 5.5、Fable 5.1 持平；浏览器场景经 Claude Cowork 跑 110 个场景，开 auto mode 时零成功，不加防护也是首个零成功的模型。对齐评估里它是所有被测模型中主动探边界、擅自联系第三方、尝试逃逸沙箱最少的，但思维链比多数前代模型更难读。RSP 结论：不跨新阈值，误对齐风险「低」；沿用 Opus 5.5 那套针对前沿模型研发（如特定 ML 加速器的内核开发）的 RSI 相关安全措施。

**发布与动态（3 条）**：Sonnet 5.5 本体——Terminal-Bench 4.0 从 Sonnet 5 的 10.3% 跳到 70.6%（Opus 5.5 为 66.4%），GDPval-AA 1844 分与 Opus 5.5 的 1846 几乎持平，价格与 Sonnet 5 相同（输入 $2 / 输出 $10 / 缓存读 $0.20），每任务成本最多低 30%，输出快 30% 以上；Haiku 5.5 数周内到。Anthropic × NVIDIA 一文把「模型内安全措施 → Managed Agents 凭据保险库 → OpenShell 运行时策略」三层写成产品组合，凭据 agent 永远看不到、执行由 agent 外部逐条放行。xAI Team Bots 是给团队共享的 Grok Bot：上下文、插件、凭据、记忆四件套，对话按人隔离但技能与修正全队共享；SpaceXAI 内部用它做每日客户简报、工程项目协调（五人团队日均 100+ PR）、数据问答（复用 45,000 张表的技能库）。

## 今日判断

- 【必看】**边界清晰的 agent 任务默认换到 Sonnet 5.5**。它在 Terminal-Bench 4.0 上超过 Opus 5.5，价格与 Sonnet 5 相同而每任务便宜最多 30%；迁移时注意：关闭 thinking 的调用要先改成 `between_tools` 设置，跨账号搬运会话会受 preserved thinking 影响。
- 【利好】**间接提示注入的裸模型成功率已经压到 0.07%–3% 量级，但厂商自己没有因此拆防护**。Anthropic 在系统卡里明确产品层仍常开注入探针；自己的 agent 也应保留输入过滤与权限隔离，把模型鲁棒性当第二层而不是唯一一层。
- 【结论】**「凭据在 agent 外、执行在 agent 外」已成两家厂商的联合产品方案**。Anthropic 托管 agent 把凭据放保险库，NVIDIA OpenShell 默认全拦、按规则放行并记录每次决策；推荐流程是从窄权限起步、看日志、让 Claude 收紧规则、用策略证明器确认。
- 【值得盯】**共享记忆正在成为企业 agent 的卖点，也是新的一致性风险**。xAI Team Bots 让一个人的修正改善全队答案；HiCoMER 则证明平铺存储会检索出与团队共识冲突的过期记忆。做团队级记忆要有有效性标记和冲突更新，不能只按相似度排序。
- 【警示】**Sonnet 5.5 的思维链比多数前代模型更难读**。系统卡把这一点与「隐藏推理时隐蔽能力高于 Sonnet 5」并列；如果监控方案依赖读 CoT 判断 agent 意图，要改用行为层与工具调用层的检查。

## 论文（自演进优先）

- **[Not All Memories Are Equal: Hierarchical Collaborative Memory for Validity-Aware Retrieval in LLM Agents](https://arxiv.org/abs/2609.30289)** · Yufei Shi 等 6 人 · 提交 2026-09-09（09-28 批次公告） —— 团队协作里记忆是异构且持续演化的：团队记忆记共识与协议，个人记忆记执行轨迹与中间进度。现有系统把所有记忆平铺、按相关性/重要性/新近度排序，会把语义相关但已过期、与团队共识冲突的个人记忆顶上来。HiCoMER 分三个组件：分层记忆冲突更新器维护团队/个人记忆的有效性，有效性感知检索器只从仍有效的记忆里取，再由记忆接地的生成器答题；作者构建两个协作场景记忆问答数据集，报告一致优于强基线。**可借鉴**：agent 记忆库给每条记忆加「有效/被替代」状态并在写入时做冲突更新，检索前先按有效性过滤再按相似度排序。
- **[AgentWorld: Benchmarking Long-Horizon Collaboration of Multi-agent LLMs](https://arxiv.org/abs/2609.31590)** · Raphael Shu 等 10 人 · 提交 2026-09-25 · HF ↑7 —— 100 个人工标注任务（另 100 个扩展变体），在 MMORPG 沙箱里 3–20 个角色与能力不对称的 agent 黑盒协作 50+ 轮。提出因果协作有效性（CCE），用动作因果图度量团队努力中真正贡献结果的比例。Gemini 3 Flash、Claude Haiku 4.5、GPT-5 Mini、DeepSeek R1-70B 最好只有 52.0% 成功率，典型失效是沟通断裂、角色混淆、跨轮无法维持共享计划。全部开源。
