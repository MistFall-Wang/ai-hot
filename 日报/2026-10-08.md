## 今日判断

- 【必看】agent 系统里的子 agent、上下文压缩、摘要、分类层应当立刻评估换 Haiku 5.5：Terminal-Bench 4.0 从 Haiku 4.5 的 0.0% 到 39.2%，价格约为 Haiku 4.5 的四分之一，且提示在 10 万 token 以内时输入 0.10 美元 / 百万；Sonnet 5.5 缓存读取减半后多数 agent 任务便宜约 20%，提示设计应把稳定前缀放最前、把长度控制在 10 万 token 内。
- 【警示】skill 自演进的验收不能只看「经验是否任务正确」：SkillPoison 用全部通过验证与词法检查的成功经验达到 95.71% 攻击成功率，手法是先堆积强化目标行为的成功经验、再抹掉约束该行为的上下文条件；提炼 skill 时必须把适用条件当成 skill 的一部分核验，并对「条件被泛化掉」的修订做对抗检查。
- 【警示】给编码 agent 开 auto-approve 等于放弃防线：六个主流 harness 在同一 GLM-5.2 底座下攻击成功率从 29.2% 升到 95.6%；命令白名单与黑名单以很小的效用代价压低攻击效果，网络隔离与只读模式代价大；上线前要测保护操作的替代执行路径。
- 【利好】长程 agent 的持久状态应由 harness 而不是对话持有：Stateless Language Agents 用少 84% 的 token 达到最强核优化基线，Advisor 只耗 0.6% token；ReFold 在渲染层可逆折叠已显示内容与已完成回合，token 省 2.5 倍且不丢成功率；按步经 MCP 下发 SOP 让绕过流程的「正确答案」从 31–49% 降到接近 0。
- 【值得盯】「从经验中学习」有了两个会说不的基准：ServeLearnBench 发现五种学习 harness 都有持续适应破坏已正确行为的情况、探索不足是主要瓶颈；Learn2Play Bench 发现保留完整记录胜过总结成规则、换 harness 能同时提分和降成本；而一篇受控实验显示多 agent 推理里的持久记忆层对准确率无可检出影响，所有记忆层收益都应报配对对照与置信区间。

## ⭐ 自演进重大发现

- **自演进的新红线：全部任务正确、能过验证的经验也能毒化 skill 提炼**。《SkillPoison: Progressive Skill Poisoning via Successful Experiences》（2026-10-06 提交）针对「把成功经验蒸馏成持久 skill」的自改进 agent：不注入任何恶意触发、行为或假事实，而是先构造一组强化目标行为的成功经验，再移除约束该行为何时适用的上下文条件，让 skill 提炼器把有用行为泛化到不该用的场景。三个基准上攻击成功率 95.71%，所有注入经验保持任务正确并通过验证与词法检查。此前的 skill 攻击靠注入恶意内容、易被检测且难以沉淀为持久 skill；这条结果说明 skill 自演进管线的验收必须核验适用条件本身，而不只是经验是否成功。
- **对齐可以自改进的硬数据**。《SIGMA: Self-Improving Alignment Generalization from a Model Spec》（2026-10-06 提交）针对「能力能靠可验证反馈递归自改进、对齐却依赖外部监督」的失衡：只给模型一份描述期望行为的 Model Spec，让模型作为任务设计 agent 合成多样的对齐两难场景并转成训练任务，再用模型自己当奖励模型做 SFT 与基于 rubric 的 RL。只在单轮对话数据上训练，却在多轮 agent 环境上泛化：AgentHarm 有害率 22.6 → 14.8，Agentic Misalignment 79.1 → 3.8，优于 Deliberative Alignment 与 Constitutional AI 基线且保持通用能力。消融显示兼顾无害与有用的 Spec、测试时的安全推理、任务设计 agent 产出的高质量 rubric 三者缺一不可。
